# استطلاع DawaNetwork للصيادلة

نموذج استطلاع ويب مستقل (HTML/CSS/JS عادي، بدون أي إطار عمل) لمشروع DawaNetwork الجامعي، بتصميم RTL عربي كامل وبنفس هوية الألوان المختارة (Emerald / Deep Teal).

هذا **ليس** Google Form — صفحة ويب قائمة بذاتها يمكن رفعها كما هي على أي استضافة ثابتة (Netlify، Vercel، GitHub Pages، أو حتى فتح `index.html` مباشرة).

## الحالة الحالية: هل هذا نموذج حي أم نسخة تجريبية؟

**النموذج متصل بقاعدة بيانات Supabase ويعمل بشكل حي مع لوحة إدارة متكاملة.**

- الكود الخاص بالاتصال بـ Supabase (`supabaseClient.js`) يدعم الاتصال المباشر مع Fallback تلقائي عبر REST API.
- بمجرد ملء `config.js` بمفاتيح المشروع، يرسل النموذج كل رد إلى جدول `survey_responses`.
- تتوفر لوحة إدارة وتحليلات متكاملة في `admin.html` لعرض النتائج والرسوم البيانية وسجل المشاركين وتصدير ملفات Excel (CSV).

## خطوات التشغيل الفعلي (جمع ردود حقيقية عبر الإنترنت)

1. أنشئ مشروعًا مجانيًا على [supabase.com](https://supabase.com).
2. افتح **SQL Editor** في لوحة تحكم المشروع، وشغّل محتوى الملف `supabase/schema.sql` كما هو. هذا ينشئ جدول `survey_responses` مع صلاحيات (Row Level Security).
3. من **Project Settings → API**، انسخ قيمتي:
   - `Project URL`
   - `anon public` key
4. افتح `config.js` وضع القيمتين مكان الفراغين.
5. ارفع كل محتوى هذا المجلد كما هو إلى أي استضافة ثابتة (Netlify / Vercel / GitHub Pages...).

## التشغيل محليًا للمعاينة

لا حاجة لأي تثبيت. من داخل هذا المجلد:

```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000 في المتصفح
# وللوحة الإدارة: http://localhost:8000/admin.html (رمز الدخول: 1234)
```

## ما الذي تم تنفيذه

- جميع الأسئلة كما في المسودة الأصلية، مع عرض فكرة DawaNetwork بعد أسئلة التجربة الحالية مباشرة (القسم الثالث) حتى لا تتأثر إجابات الصيادلة على القسمين الأول والثاني بمعرفتهم المسبقة بالفكرة.
- شريط تقدم أعلى الصفحة يزيد مع كل سؤال.
- تنقّل تالي/سابق مع الاحتفاظ بكل الإجابات المدخلة عند الرجوع للخلف.
- التحقق من الإجابات الإلزامية قبل الانتقال، مع رسائل خطأ نصية واضحة (وليس الاعتماد على اللون وحده).
- خيار "أخرى" مع حقل نصي حر أينما ورد في الاستبيان الأصلي.
- خطوة مراجعة نهائية قبل الإرسال، يمكن منها الضغط على أي سؤال للعودة وتعديله مباشرة.
- رسالة تأكيد بعد الإرسال.
- واجهة عربية RTL بالكامل (`dir="rtl"` و`lang="ar"`) مع عرض طبيعي للمصطلحات الإنجليزية المدمجة (DawaNetwork، WhatsApp).
- تصميم أنيق مع شعار DawaNetwork الرسمي ومقيد بهوية الألوان الطبية الحديثة (Emerald `#0CD482`، Deep Teal `#0C2A35`).
- استجابة كاملة للجوال وسطح المكتب، وتركيز لوحة مفاتيح مرئي على كل عنصر تفاعلي.


## القيود المعروفة في بيئة الاختبار هذه (لن تظهر عند الاستضافة الفعلية)

عند بناء هذا الملف لم يكن لدي اتصال إنترنت لتحميل خط Google Fonts (Cairo) أو مكتبة `@supabase/supabase-js` من الشبكة التي استخدمتها للاختبار الداخلي، فظهرت أخطاء تحميل لهذين المصدرين في اختباراتي المحلية فقط. هذا لا يعكس مشكلة في الكود؛ فور رفع الملفات لاستضافة حقيقية متصلة بالإنترنت العام، سيُحمَّل الخط وتعمل مكتبة Supabase بشكل طبيعي. تم اختبار تدفق الاستطلاع كاملًا (الأسئلة، التحقق، "أخرى"، الاشتراك، المراجعة، الإرسال المحلي، التصدير) بمتصفح آلي محليًا والتقاط لقطات شاشة للتأكد من سلامته.

## الملفات

```
index.html            هيكل صفحة الاستبيان الأساسية
styles.css             التصميم وهوية الألوان (Emerald / Deep Teal)
questions.js            محتوى الاستبيان (الأسئلة الـ23 والأقسام)
app.js                  منطق الاستبيان والتحقق والعرض والإرسال
admin.html            لوحة تحكم الإدارة وعرض النتائج والتحليلات
admin.css             تصميم لوحة الإدارة والجداول والرسوم البيانية
admin.js              محرك التحليلات وحساب النسب والتصدير لإكسل
supabaseClient.js        طبقة الاتصال بـ Supabase مع دعم Fallback
config.js                إعدادات الربط بقاعدة البيانات (URL ومفتاح Anon)
.env.example             توثيق المتغيرات بصيغة ملفات البيئة
supabase/schema.sql        جدول الردود وصلاحيات الأمان (RLS)
```
